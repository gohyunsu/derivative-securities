# 주식·채권·파생금융상품 3: 실증

계약의 현금흐름에서 선도·선물의 가격과 기업의 헤지 결정까지 이어지는 한국어 학습 가이드입니다. 미시·거시경제학을 공부한 학부생이 각 개념을 처음 만나는 순서에 맞춰 설명합니다.

**[학습 사이트 보기](https://gohyunsu.github.io/derivative-securities/)**

## 학습 경로

| 장 | 주제 | 슬라이드 |
| --- | --- | ---: |
| 01 | 계약의 현금흐름과 복리 | 7 |
| 02 | 지급액, 시장 구조, 거래 목적 | 14 |
| 03 | 변동성과 주요 손실 사례 | 36 |
| 04 | 선도·선물의 결제와 증거금 | 30 |
| 05 | 무차익 선도가격과 베이시스 | 24 |
| 06 | 선도 헤지와 하방 현금흐름 위험 | 24 |

각 슬라이드의 이미지와 설명을 나란히 배치했습니다. 수식은 현금흐름과 단위에서 출발해 단계별로 유도하며, 국내외 사례·개념 도식·심화 설명을 함께 제공합니다. 사이트에서 전체 검색과 슬라이드 확대를 사용할 수 있습니다.

## 로컬 실행

Node.js 20 이상에서 원고를 수정한 뒤 사이트와 LaTeX 문서를 다시 생성할 수 있습니다.

```powershell
npm install
npm run build
npm run check
python -m http.server 8765 --directory docs
```
